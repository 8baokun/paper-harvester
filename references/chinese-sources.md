# 中文免费 / 半免费源

## 1. 国家哲学社会科学文献中心（NCPSSD）★ 已支持自动下载
- 官网：https://www.ncpssd.cn
- 社科院牵头，注册后免费检索 / 阅读 / 下载中文社科全文
- 覆盖：中文期刊（2373种）、外文期刊、古籍、集刊
- 注册地址：https://www.ncpssd.cn/register （免费，无验证码）
- **自动化能力**：
  - ✅ 检索：无需登录即可检索题录
  - ✅ 下载：提供账号密码后自动登录 + 下载 PDF
  - ✅ Cookie 持久化：首次登录后保存 Cookie，后续免登录
  - ⚠️ 限制：无稳定开放 API，搜索结果依赖页面解析
  - ⚠️ 并发：下载间隔 ≥ 2 秒，避免触发限制
- 脚本：`scripts/search_ncpssd.py`

## 2. PubScholar
- 官网：https://pubscholar.cn
- 中科院体系公益平台，元数据多，部分 OA 全文
- 适合补中文期刊、预印本、专利、科技报告

## 3. 知网 / 万方 / 维普
- 元数据可发现，全文通常要机构订阅
- Agent 只做：构造检索式、读用户粘贴的题录、提示走机构账号
- 不尝试绕过验证码 / 付费墙

## 4. 国家图书馆 / 高校图书馆
- 文津搜索、超星期刊、读秀、文献传递
- 校外可用国图读者卡；校内优先 WebVPN / CARSI

## 5. 其他公益源
- 国家科技图书文献中心 NSTL
- 中国科技论文在线 / 国家科技报告服务系统
- 各高校机构仓储（学位论文 OA 部分）

## 6. 微信公众号文章 ★ 已支持自动提取
- 公众号推送的学术文章（mp.weixin.qq.com/s/xxx）
- **自动化能力**：
  - ✅ 正文提取：requests + BeautifulSoup 解析
  - ✅ 格式转换：HTML → Markdown（html2text）
  - ✅ 图片下载：可选下载文章内嵌图片到本地
  - ✅ 批量下载：从 URL 列表文件批量处理
  - ⚠️ 限制：只支持公开可访问的文章链接
  - ⚠️ 反爬：微信有频率限制，批量下载间隔 ≥ 2 秒
- 脚本：`scripts/download_wechat.py`
